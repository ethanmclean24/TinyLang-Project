# StudyLang

## Purpose
Most study/flashcard websites are overly complex and push you to a paid tier. Making a simple language with easy inputs and outputs would make it easy for students to add course materials (like terms or questions) and study using simple console input/output.

## Target Users
Students looking for a way to study their course material. Little to none prior knowledge needed.

## Design Principles
1. Simplicity
2. Readability
3. Built in functions

## Initial Features
- `let` variable declarations
- Boolean values
- `show` for printing, `ask` for getting console inputs.
- Numeric values
- While loops
- Indentation for coding blocks

## Week 1 Run
```bash
python main.py
```
